## Грабли (важно)

- **Bash на этом ПК съедает обратные слэши в heredoc** (`\s`, `\.`, `\\`): JS/регулярки писать через Write/Edit, не через `node - <<EOF`. Обязательно перечитывать регулярки после правки.
- Капри запускать только из обычного терминала: шеллы Claude/Codex видят другую копию `%APPDATA%` (MSIX).
- Android-репо в CRLF: после правок `sed -i 's/\r*$/\r/' файл`. Локальной сборки нет — только CI; Kotlin проверять глазами (пример ловушки: `Array<String>` не передаётся в `setItems`, нужен `Array<CharSequence>`).
- GitHub иногда отвечает 500 на push — повторять с паузой.
- Comfy Desktop: yaml моделей содержит закомментированный пример `base_path` — брать строку без `#`.
- 8 ГБ VRAM: Ollama выгружается перед ComfyUI (`beforeJob`); роутер не грузит вторую модель, если включена ролевая.
- Скачивание, установка, пуш — только после явного «да» Danyal (сегодня «да» было на пуш и на модели видео).
