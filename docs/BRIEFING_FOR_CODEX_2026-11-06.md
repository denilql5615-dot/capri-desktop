## 2. Что выполнено в текущей сессии

### А. Серверная часть и Windows Hub (`capri-desktop`)
1. **Сквозной путь файлов и безопасность артефактов:**
   - Артефакты изолируются в `hubArtifactRoot/<sessionId>/`.
   - Внедрена валидация путей против path traversal, белый список расширений, безопасное открытие/копирование с `COPYFILE_EXCL`.
   - Проходит живой юнит-тест `tests/live-hub-file-flow.test.js`.
2. **Голосовой ввод на ПК (STT):**
   - Внедрён IPC-эндпоинт `agents:voice-stt` на базе локального Whisper (`src/main/whisper-server.py`).
   - В UI окна «Чаты» добавлена кнопка `🎤` (`.agents__mic`) с записью через Web Audio API, генерацией 16 кГц WAV и подстановкой текста в поле задачи.
3. **Приём файлов с мобильного моста:**
   - В `agentSend` (`src/main/main.js`) добавлен парсинг массива `files`: сохранение base64-вложений в `hubArtifactRoot/uploads/<sessionId>/<filename>` и добавление путей файлов к промпту задачи.
4. **Автообновление квот Antigravity:**
   - Парсер `parseAgyStatusLineQuota` разбирает 5 окон `statusLine` (`gemini-5h`, `gemini-weekly`, `gemini-argon-wtu-weekly`, `3p-5h`, `3p-weekly`).
   - Фоновое кеширование на 120 с, маркер устаревания `stale` (> 600 с), кнопка ручного обновления в UI.
5. **Авто-резолв моделей и устранение ошибок 404 и 500:**
   - Ошибка 404: возникала из-за того, что на порту 8770 висел старый процесс до добавления роутов `/agents`. Процесс перезапущен.
   - Ошибка 500: возникала, если клиент передавал пустую строку `model: ""` или модель другого агента (например, модель Gemini в сессию Claude). `agentSend` теперь автоматически подставляет первую валидную модель выбранного агента.
   - Ошибки моста в `phone.js` возвращают статус 400 и внятное описание вместо глухой 500.
6. **Запуск через Win32:**
   - Подтверждено железное правило: запуск только через `Win32_Process.Create` (WMI), чтобы процесс не умирал при завершении консольной сессии или субшелла.
   - Все 137 unit-тестов проходят (`node --test tests/*.test.js`).

## 4. Памятка по среде и запуску

- **Запуск Capri Desktop на ПК (строго через Win32):**
  ```powershell
  $exe = "$env:LOCALAPPDATA\Programs\capri-desktop\Capri Desktop.exe"
  Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{ CommandLine = "`"$exe`"" }
  ```
- **Проверка порта:** `netstat -ano | findstr 8770`
- **Проверка эндпоинтов моста:**
  ```powershell
  curl.exe -i -H "X-Capri-Token: <токен_из_phone-link.txt>" http://127.0.0.1:8770/agents
  ```
- **Android APK CI:** коммиты в `main` репозитория `D:\Capri\capri-android-ref` автоматически триггерят сборку и выкладывают APK в `https://github.com/denilql5615-dot/capri-android/releases`.
