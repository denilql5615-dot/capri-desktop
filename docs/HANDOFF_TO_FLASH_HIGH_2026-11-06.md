2. **Проверить облачные картинки и видео по провайдерам.** Различай выбранную модель-разум и медиаинструмент её сервиса. Для Claude Code, Codex и Antigravity зафиксируй по каждому формату: инструмент доступен, лимит, недоступен или тест не прошёл. Не выдавай описания, поддельные ссылки, программно нарисованный файл или местный ComfyUI/Wan за облачную генерацию. Сейчас запрет локальной генерации передаётся в инструкцию агенту; это не песочница для его инструментов. Если нужна гарантия, подключай явно разрешённый облачный адаптер с проверяемым результатом. При отсутствии инструмента показывай честное состояние и не включай платные API или overages самовольно.

Затем добавить таймаут, один общий запрос на обновление, кеш и маркировку устаревших данных. Не отправляй пробные промпты для квот, не собирай сырой статусный JSON и не читай токены. Если скрытый запуск не подтвердится, оставь снимок с понятным статусом. Официальный справочник: https://antigravity.google/docs/cli/statusline/
