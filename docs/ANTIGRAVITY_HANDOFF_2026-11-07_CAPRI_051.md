## Следующий прогон: Flash → Sonnet → Opus внутри Antigravity

1. Сверить владельца порта 8770 по PID и абсолютному пути. Развернуть согласованную Windows-сборку с сохранением профиля. Capri на Windows запускать только через `Win32_Process.Create`. После смены экземпляра проверить, что именно новый процесс держит 8770 и что прежний каталог сессий читается.
2. Из Android создать отдельный тестовый чат Antigravity. Использовать безличный файл с уникальной тестовой строкой. Проверить диктовку, прикрепление, сохранение файла под `hub-artifacts/uploads/<sessionId>/`, ответ и открытие артефакта. Для очереди свернуть Hub и проверить уведомление с переходом в чат. Появление уведомления и появление в HyperIsland фиксировать отдельно.
3. Выполнить одинаковый набор проверок последовательно на `gemini-3.8-flash-high`, `claude-sonnet-5-5-medium`, `claude-opus-5-5-medium`. Для каждого использовать отдельную сессию и проверить фактический ID модели в истории на ПК. Записать время, итог, ошибку и квоту, если она доступна. Не запускать следующий прогон параллельно с предыдущим.
4. На Xiaomi вручную проверить Дом, трей в портрете и альбоме, перетаскивание, закрепление, «Скрыть», возврат плиткой, виджеты, зарядный экран, звук и AR. USB-управление касаниями в текущих настройках HyperOS недоступно.

Отдельные незакрытые задачи из исходного брифинга: скрытое автообновление квот Antigravity через ConPTY и ручная проверка `feat/agent-desktop` перед слиянием. Этот прогон их не закрывает.
